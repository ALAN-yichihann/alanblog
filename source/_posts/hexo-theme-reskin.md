用别人写的主题，早晚会想改。改配色是最容易上手的入口，但改到后面会发现，真正影响观感的不是颜色，而是间距和字重的节奏。

## 先定颜色

主题的强调色通过 CSS 变量注入，改配置就能生效：

```yml
accent_color: '#496b8c'
accent_soft: '#dce8f0'
```

这两个值会被写进 `:root`，原本的深层样式再通过 `var(--accent)` 引用。所以在配置里改一次，进度条、链接、局部底色都会跟着动。

### 低饱和度的好处

试过一段时间的亮蓝色，第一天觉得精神，第三天就开始刺眼。后来换回灰蓝，页面安静下来，读长文的疲劳感明显下降。

我的经验是：强调色只负责“提示”，不负责“吸引”。饱和度越高，它在页面里出现的次数就该越少。

## 再调间距

主题默认的正文行高和段距已经比较克制，但中文和英文的观感差别很大。中文段落更密，行高需要再放一点：

```css
.article__content {
  line-height: 1.95;
}

.article__content p {
  margin: 0 0 1.35em;
}
```

改之前记得先找到变量，别到处写死数值：

| 想改的东西 | 优先改的地方 |
| --- | --- |
| 全局配色 | `:root` 里的 CSS 变量 |
| 正文行高 | `.article__content` |
| 卡片间距 | `.post-list` 相关类 |
| 侧栏宽度 | `.site-sidebar` |

## 一个容易忽略的细节

深色模式不是简单地把背景变黑。主题的做法是把强调色往浅色方向混一档，避免在深色背景上还用原来的深灰蓝：

```css
@media (prefers-color-scheme: dark) {
  :root {
    --accent: color-mix(in srgb, #496b8c 68%, #f3f6f8);
  }
}
```

`color-mix` 现在浏览器支持已经很好了，用它比手算 RGB 省事。

## 改完之后

前后对比一下，其实变化不大——颜色更灰，行距更松，标题的字重没有动。但整体的“呼吸感”确实变了。

换肤这件事，改到最后往往不是把页面改得更花，而是把多余的东西一点点拿掉。
